Base de données joueurs

Si Supabase est configuré (fichier supabase-config.js), la base est la table « joueurs » de Supabase, à modifier dans son « Table Editor ». Sinon, la base est le fichier joueurs.csv, à modifier dans Excel ou Google Sheets (enregistrer en « CSV UTF-8 », séparateur « ; »). Place-le à côté de index.html, et les images dans le dossier photos (colonne « photo » : par exemple photos/dupont.jpg).
