1. Charger la base

Dans Excel, enregistre la feuille JOUEURS en « CSV UTF-8 », puis choisis le fichier. Rien n'est envoyé sur internet : le fichier est lu dans ton navigateur. Colonnes lues : id, Nom, Poste (obligatoires) ; date de naissance, nationalite, club actuel, Profil, les 12 statistiques, Note Globale, specialite, poids, taille, photo (facultatives). Les données douteuses sont signalées mais n'empêchent pas l'import.
