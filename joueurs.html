1. Charger la base

Dans Excel, enregistre la feuille JOUEURS en « CSV UTF-8 », puis choisis le fichier. Rien n'est envoyé sur internet : le fichier est lu dans ton navigateur. Colonnes attendues : id, Nom, Poste, date de naissance, nationalite (obligatoires) ; Profil, les 12 statistiques, Note Globale, specialite, poids, taille, photo (facultatives).
